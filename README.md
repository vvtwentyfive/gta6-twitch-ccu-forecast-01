Forecasts how many people will be watching Grand Theft Auto VI live on Twitch in each hour of its release day (hours 2-24, UTC) as five quantiles per hour, from the first hour's count, the pre-release baseline, and the launch-day shapes of past big game launches.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
